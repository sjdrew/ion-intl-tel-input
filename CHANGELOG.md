# Changelog

## [2.0.6] - 2025-07-31

### Updated
- Updated `google-libphonenumber` from `^3.2.28` to `^3.2.42` (latest version)
- Updated `@types/google-libphonenumber` from `^7.4.17` to `^7.4.30` (latest types)

### Improved
- Enhanced phone number validation with latest Google libphonenumber rules
- Better support for newer phone number formats and area codes
- Performance improvements from 14 patch releases
- Security updates and bug fixes

### Technical
- Removed custom validation code (no longer needed with updated library)
- Maintained backward compatibility
- All existing features preserved
